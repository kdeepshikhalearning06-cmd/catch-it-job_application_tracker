# Catchit

Catchit catches what companies ask you to do, before it slips.

A fresher applying to several roles a week connects Gmail once. Catchit finds assessment links, interview invites and deadlines in company emails, proposes "do X by Y", and the user confirms. A reminder email arrives the morning it is due.
